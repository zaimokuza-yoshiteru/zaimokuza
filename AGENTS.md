# zaimokuza — personal site

Personal blog of Zaimokuza: a quote-led opening, blog, open-source works, and experience timeline. Design language derived from a replica of mimo.mi.com — warm beige palette, serif display type, custom cursor, and a mouse-following invert mask over the hero.

## Commands

- `npm run dev` — Vite dev server
- `npm run build` / `npm run preview` — production build (`tsc --noEmit` first) / preview
- `npm run test:blog` — validate the nine-question article, source manifest, sketch assets and run all Python / TypeScript examples (Python 3.10+ with SQLite FTS5 and Node.js 24).
- `node scripts/fetch-github.mjs` — regenerate `src/data/projects.json` from the GitHub API (requires the `gh` CLI, authenticated). Pulls non-fork repos of `zaimokuza-yoshiteru`, skips the repos listed in `EXCLUDE` (this site itself), sorts by stars then recency.

## Structure

- `src/data/profile.ts` — single source of truth for ALL copy (hero identity/quote/location in en+zh, project use-case descriptions, social links, experience timeline). Edit this file to change site content; the `Profile` interface documents the shape.
- `src/data/projects.json` — generated by `scripts/fetch-github.mjs`; do not hand-edit.
- `src/components/` — `Nav`, `Hero` (also exports `HeroText`, reused by the invert mask), `HeroInvert`, `Blog`, lazy-loaded `BlogArticle`, shared `SectionHeader`, `Projects`, `Experience`, `Footer`, `CustomCursor`.
- Blog metadata and shared UI copy live in `profile.blog` / `profile.articleUI`; posts use unique stable slugs, ISO dates and excerpts, sorted newest first. Long-form copy lives in `src/data/articles/<article>.md`, selected by each post's `article` key; legacy `paragraphs` remain supported. Home shows up to five posts; `#/blog` shows all, and `#/blog/<slug>` renders an article. `src/lib/navigation.ts` prefixes links with the deployment base.
- Markdown articles render with `react-markdown` and GFM tables. An `example` fenced block containing `q01` through `q09` (plus `q04-cache`) renders Python/TypeScript tabs, copy and downloads from `src/data/articles/examples/`; these standalone teaching programs are excluded from browser TypeScript checking and executed by `test:blog`. Local evidence notes live in `docs/research/` and are not rendered in the blog. Source quotations are verbatim, explained in Chinese, and tracked in `context-management.sources.json`; distinguish them from illustrative implementations. Sketches live in `public/blog/context-management/` and their runtime URLs are base-prefixed. Article dependencies and body load only when opening an article.
- Home shows five projects initially; each expansion adds up to five and moves focus to the first new entry. Counts derive from data. `useRevealOnScroll` observes dynamically inserted content too.
- `src/interactions.ts` — `useRevealOnScroll` hook (IntersectionObserver adds `.visible` to `.reveal` elements, once).
- `src/index.css` — Tailwind v4 entry; design tokens live in `@theme`.
- `src/assets/geist-mono-regular.ttf` — self-hosted font behind `font-mono-num`.
- `public/lottie/earth/` — Lottie assets for the hero globe animation (`data.json` + `images/`).
- `.github/workflows/deploy.yml` — builds on push to `main` and publishes `dist` to GitHub Pages.

## Deployment / base path

The site is served from `https://<user>.github.io/zaimokuza/`, so `vite.config.ts` sets `base: '/zaimokuza/'` for `build` and `preview`, and `'/'` for dev. Any runtime URL to a `public/` asset or an internal link MUST be prefixed with `import.meta.env.BASE_URL` (see the Lottie fetch/`assetsPath` in `Hero.tsx`) — hardcoded leading-slash paths 404 in production.

## Dynamic GitHub Stars

- The deployed static page uses `src/hooks/useGithubStars.ts` and `src/lib/githubStars.ts` to refresh public GitHub Star counts in the visitor’s browser. It renders bundled counts first, caches API data for 15 minutes, and retains existing values on failure. No token or backend is required.
- Run `npm run test:stars` to check caching, pagination, rate limits, and failure handling. The fetch script generates only repository names, URLs and Star snapshots after sorting; Chinese descriptions live in `profile.projects`.

## Design tokens (`src/index.css` → `@theme`)

| Token | Value | Use |
|---|---|---|
| `bg-page` | `#f5f0e6` | page background (warm beige) |
| `bg-card` | `#f8f3ea` | cards — slightly LIGHTER than page |
| `bg-section` | `#ebe3d2` | tag pills / recessed fills (deepest) |
| `border-warm` | `#e3dac6` | hairline borders |
| `text-primary` | `#1f2329` | body text |
| `text-secondary` | `rgba(0,0,0,.55)` | muted text |
| `font-serif-main` | Georgia stack | hero identity and quote |
| `font-mono-num` | Geist Mono stack | numbers, dates, repo names |
| `ease-out-strong` | `cubic-bezier(.16,1,.3,1)` | the house easing — use it for all motion |

Layering rule: `bg-section` (darkest) < `bg-page` < `bg-card` (lightest). Never use pure white (`bg-white`) for surfaces.

## Homepage layout

- Home uses a shared 1100px `.site-frame`, a compact identity and quote opening, and `.home-section` with a title rail and content column on desktop; narrow screens stack these vertically. Blog, projects and experience use flat rows and warm divider lines. Section subtitles and animal mascots are removed. Work and education rows retain only dates, organization and role.

## Interaction system

- **Custom cursor**: inside `<main class="cursor-hidden-zone">` the system cursor is hidden; `CustomCursor` draws a 6px dot + 32px easing ring (80px over links/buttons). Nav and footer keep the native cursor. Disabled for touch / `prefers-reduced-motion`.
- **Hero invert mask**: `HeroInvert` is a fixed black layer clipped by `clip-path: circle(r at x y)` that eases toward the mouse while it is over the hero text. Inside the black circle it renders a white-text CLONE of `HeroText` in English — so the page reads Chinese by default and English inside the circle. Small identity and location text sits above the quote-led layout. Both languages share the continuous quote block height; narrow, touch and reduced-motion layouts omit the hidden quote spacer.
- **Reveal on scroll**: add class `reveal`; stagger via inline `transitionDelay`.
- **Article navigation**: `useActiveSection` tracks the current H2 while scrolling and after content resizing; desktop and mobile contents share the hover style through `aria-current="location"`. Article pages show a floating `BackToTop` button after 400px, with keyboard focus restoration and reduced-motion support.
- **Hero globe**: Lottie animation, lifts 20px with subtle pointer tilt on hover (`.hero-earth` rules in `index.css`).

## Conventions

- Code comments are written in **Chinese**; this document and commit messages may be English/Chinese.
- **TypeScript strict mode** (`strict` + `noUnusedLocals/Parameters`); `tsc --noEmit` is part of `npm run build`. `scripts/fetch-github.mjs` stays plain JS (Node script, outside the app).
- Tailwind v4 (via `@tailwindcss/vite`) with arbitrary values (`text-[15px]`); theme tokens only through `@theme`, no `tailwind.config.js`.
- Keep components presentational; no state management library.
