# zaimokuza

Personal blog of **Zaimokuza**. A quote-led opening, open-source works, and experience timeline in one warm, quiet page.

> **Design credit**: this site is a loving homage to the [Xiaomi MiMo homepage](https://mimo.mi.com/). Its lively interactions, elegant styling, and layout — the custom cursor, the mouse-following invert mask, the gentle reveal animations — were the inspiration and reference for everything you see here.

## Stack

React 18 · TypeScript · Vite 6 · Tailwind CSS v4 · lottie-web

## Develop

```bash
npm install
npm run dev        # dev server
npm run build      # tsc --noEmit + production build
npm run preview    # preview the production build
node scripts/fetch-github.mjs   # refresh src/data/projects.json from GitHub (needs gh CLI)
```

## Content

All copy lives in `src/data/profile.ts` — edit that one file to update the whole site. For design tokens and the interaction system, see [AGENTS.md](./AGENTS.md).

The hero defaults to Chinese; its pointer mask reveals English. A small identity/location header introduces the quote, with consistent text sizing throughout and the source reduced to the work title and year. The Chinese quote is preserved verbatim, with an English translation inside the mask. Project titles use the repository names; Chinese use-case descriptions are curated in `profile.projects`; GitHub metadata remains generated by the fetch script.

## Dynamic GitHub Stars

The deployed static GitHub Pages site refreshes Stars **in the visitor's browser**, without a backend or another deployment. It first renders the bundled snapshot, then reads a validated browser cache and requests the public GitHub repository API when needed. Counts are cached for 15 minutes; refresh happens on page load, not continuous polling. Requests time out after 8 seconds. Offline, rate-limited, or invalid responses retain the previous counts. Tokens are never sent or embedded in the site.

The API returns `stargazers_count`; a repository-list request covers up to 100 repositories, with pagination as needed (bounded to 10 pages). Unauthenticated requests are limited to 60 per hour per public IP, so users on a shared network can still encounter limits. See [GitHub repository API](https://docs.github.com/en/rest/repos/repos#list-repositories-for-a-user) and [rate limits](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api).

Run `npm run test:stars` to verify cache expiry, failures, pagination, zero counts, and cancellation. Adding repositories or changing their Chinese descriptions still requires refreshing the snapshot/content and deploying; live refresh changes only Star counts, preserving project order while reading. The theme-library experiment is always displayed last.

The implemented A prototype and future 3D directions are documented in [docs/3d-directions.md](./docs/3d-directions.md).

## Deploy

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds and publishes `dist` to GitHub Pages. The site is served from the `/zaimokuza/` sub-path, so Vite sets `base` accordingly for builds — reference static assets through `import.meta.env.BASE_URL`, never with a leading `/`.
